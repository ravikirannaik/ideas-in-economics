# Ideas in Economics (Doing Economics)

**A film-based introduction to economic thinking** | FLAME University | 2 Credits | Level 100

---

Economics is a way of understanding the world. This course uses six films as a gateway to fundamental economic ideas, pairing each with a Nobel Prize-winning contribution that shaped how economists think about markets, behavior, poverty, growth, and the environment.

No prior knowledge of economics is required. By the end of this course, you will have developed a strong grasp of economic reasoning and its applications to everyday life, policy, and the Indian economy.

## Course Features

| Feature | Description |
|---------|-------------|
| :movie_camera: **Film Analysis** | Each module anchors on a feature film, with scene-by-scene economic deconstruction |
| :medal: **Nobel Focus** | Biographical profiles of laureates whose work illuminates each module's theme |
| :india: **Indian Context** | Dedicated essays connecting economic concepts to the Indian economy |
| :joystick: **Interactive Sims** | 30+ browser-based simulations from the [Introduction to Economics](https://dmccreary.github.io/economics-course/) open textbook |
| :pencil: **Quizzes** | 10-question self-assessment per module with explanations |
| :books: **Glossary** | 120+ terms defined with examples |

## Getting Started

1. Begin with [Module 1: Understanding Economic Thinking](modules/01-economic-thinking/index.md)
2. Watch the assigned film before or alongside the module reading
3. Explore the interactive simulations linked in each module
4. Test yourself with the end-of-module quiz
5. Read the [Indian Context](indian-context/index.md) essays for local applications
